## 1. 產品簡介

### 這是什麼

AirTTY A1 是一台**可攜式無線 console 伺服器**。把 USB 序列（USB-to-serial）轉接線的一端插在 AirTTY A1 上、另一端接到交換器／路由器／防火牆／伺服器的 console 埠，你就可以用**筆電、手機或平板，透過 WiFi 或藍牙無線連進那台設備的 console**。

它解決的是機房裡最熟悉的幾個痛：

- 不必再蹲在機櫃前、把筆電擱在膝蓋上接 console 線。設備接好後，人可以坐回椅子上操作。
- 不必為了一條 console 線在機櫃前後來回穿梭；線留在設備上，你帶著筆電走。
- 設備網路掛掉（帶外管理／OOB 情境）時，console 是最後一條路 —— AirTTY A1 讓這條路變成無線的。
- 內建電池，現場沒有插座也能用。

一台 AirTTY A1 可同時服務多人：同一個 console 畫面可以多人同時看、同時打字（適合「一人操作、其他人監看」的教學或值班交接情境）。

## 2. 開箱與開機

### 2.1 各部位

- **正面**：電源鍵，周圍環繞 5 顆綠色電量燈。
- **頂部**：2 顆藍燈 + 1 顆紅／橘燈（記憶卡指示）。
- **一端**：RJ45 網路孔、USB-A 埠。
- **另一端**：記憶卡插槽、micro-USB 充電孔。

> 📷 *（截圖待補：各部位與指示燈位置）*

### 2.2 開機與關機

1. **開機**：長按電源鍵約 **5 秒**後放開。
2. 等待約 **1 分鐘**，裝置的 WiFi 名稱就會出現在你的筆電／手機的 WiFi 清單裡 —— 看得到 SSID 就代表開機完成。
3. **關機**：同樣長按電源鍵約 **5 秒**。關機前請先確認沒有正在進行的作業（例如檔案上傳、韌體傳輸）。

> ⚠️ **兩顆藍燈不是電源指示燈**。AirTTY A1 開機完成、但沒有人在使用時，**兩顆藍燈都是熄的**，這是正常狀態。判斷「有沒有開機成功」請看 WiFi 名稱有沒有出現，不要看藍燈。

### 2.3 燈號速查表

| 燈 | 位置 | 狀態 | 意思 |
| --- | --- | --- | --- |
| **藍燈 A**（靠近紅燈那顆） | 頂部 | 亮 | **console 正在被使用中** —— 目前至少有一條連線（網頁終端／Telnet／藍牙／SSH 任一）接在序列埠上 |
| | | 滅 | 目前沒有人連著 console |
| **藍燈 B**（遠離紅燈那顆） | 頂部 | 亮 | **有裝置連上本機 WiFi** —— 至少一台筆電／手機關聯到 AirTTY A1 的 WiFi |
| | | 滅 | 沒有裝置連著本機 WiFi |
| **紅／橘燈** | 頂部，藍燈旁 | 滅 | 沒有插記憶卡 |
| | | 插卡瞬間閃約 5 下 | 系統正在讀取卡片 |
| | | 恆亮 | 卡片已就緒 |
| | | 閃爍 | 正在讀寫卡片 |
| **綠燈 × 5** | 正面，電源鍵周圍 | 短按電源鍵後亮起 6～7 秒 | **電量**：每顆約 20%（4 顆亮 ≈ 80%）。充電中時，代表當前級距的那一顆會閃爍 |
| **RJ45 綠燈** | 網路孔 | 恆亮 | 網路線已接上、實體連線正常 |
| **RJ45 橘燈** | 網路孔 | 閃爍 | 網路孔上有流量 |

> 💡 **開機過程中頂部藍燈可能短暫亮起**，開機完成後會自動回到上表的語意，不需要理會。

### 2.4 充電

- 用 micro-USB 線接上 **5V / 1A** 的充電器即可充電。
- 短按電源鍵可查看電量（綠燈顯示）。原廠設計上，短按同時也會啟動 USB 對外供電模式；由於 AirTTY A1 的 USB 埠已接序列轉接頭使用，請把這個按鍵單純當作「看電量」用。
- 管理介面（見 §3）的右上角會顯示「⚡ 充電中」或「🔋 未在充電」。
  **本機硬體不提供電量百分比讀值**，要看電量請按電源鍵看綠燈數量。
- 建議：**同時使用藍牙與序列轉接頭時，全程接著充電線**使用，供電較穩定（原因見 §7 的「藍牙或序列埠突然消失」）。

## 3. 第一次連線

第一次拿到機器，請照這個順序走一次，之後就熟了。

### 3.1 連上裝置的 WiFi

1. 開機（§2.2），等 WiFi 名稱出現。
2. 在筆電／手機的 WiFi 清單中選擇 AirTTY A1 的 WiFi 名稱（SSID）：**`AirTTY-A1-xxxx`**，
   其中 `xxxx` 是每台不同的識別碼（同一批機器靠它分辨）。
   **出廠預設 WiFi 密碼為 `AirTTY-A1`，每台都相同（見 §8.4）。**
3. 連上後，你的電腦會取得 `192.168.10.x` 的 IP。

> 💡 **也可以走網路線**：用一條網路線接 AirTTY A1 的 RJ45 孔到你的筆電，一樣會拿到 `192.168.10.x` 的 IP，後續步驟完全相同。現場 WiFi 環境很吵時這條路更穩。

### 3.2 開啟管理介面

1. 瀏覽器輸入 **`http://192.168.10.1`**。
2. 登入畫面：使用者名稱 `root`，密碼出廠預設為 **`AirTTY`**（若已更改請用新密碼）。
3. 登入後，從左側選單進入 **AirTTY → 儀表板**。

> 📷 *（截圖待補：管理介面登入畫面）*

> 🔒 **強烈建議**：拿到機器後立刻更改管理密碼（左側選單 **系統 → 管理權**）。這組密碼同時是管理介面、SSH 與裝置 Shell 終端的密碼。

> ℹ️ **AirTTY A1 有兩個 IP，日常只會用到第一個**
>
> | 什麼時候 | 位址 | 說明 |
> | --- | --- | --- |
> | **平常**（開機正常使用） | **`192.168.10.1`** | 管理介面、網頁終端、Telnet 4001／4002、SSH 都走這個。本手冊其他章節出現的位址都是它 |
> | **救援模式**（開機時按住 RESET 鍵不放） | `192.168.1.1` | 機器停在開機程式（bootloader）的韌體更新頁，**只有重刷韌體時才會用到**。這個位址寫死在開機程式裡，不會跟著上面那個一起改 |
>
> 救援模式的畫面是一頁英文的 `FIRMWARE UPDATE`，沒有 AirTTY 的選單。
> **正常使用時不會、也不該進到那裡**；不小心進去了，直接斷電再開機即可回到正常模式。
>
> 💡 若你把上面的 `192.168.10.1` 改成自己的網段（管理介面 **網路 → 介面 → LAN**），
> 請自行記下新位址；救援模式那個 `192.168.1.1` 不受影響，永遠是它。

### 3.3 儀表板導覽

儀表板（AirTTY → 儀表板）是日常操作的主畫面，由上而下依序是：

> 📷 *（截圖待補：儀表板總覽）*

| 區塊 | 一句話說明 |
| --- | --- |
| **頁首** | 顯示裝置名稱、WiFi 名稱、韌體版本與充電狀態；裝置時鐘明顯不準時，這裡會出現**「以瀏覽器時間校時」**按鈕（見 §6.4） |
| **序列裝置** | 每個插上的 USB 序列轉接頭一張卡：設定鮑率等序列參數、設定連線密碼、看目前有誰連著、可單獨中斷某一條連線 |
| **上游 WiFi（WAN）** | 讓 AirTTY A1 自己去連一個熱點或分享器取得對外網路；目標網路的名稱與密碼也在這張卡設定（見 §6） |
| **進階** | 連往序列埠細部設定，以及**裝置 Shell 終端**（AirTTY A1 自己的 Linux shell，供進階使用者用；不是被接設備的 console） |

> 💡 **藍牙與 SSH 的開關、狀態與連線指引不在儀表板上**，改放在隔壁的 **「連入方式」** 頁（見下表）。
> 這樣安排是為了讓儀表板只留「現場天天要用」的東西，頁面載入也更快。

除了儀表板，AirTTY 選單下還有五個頁面：

| 頁面 | 用途 |
| --- | --- |
| **連入方式** | 藍牙序列（BLE）、藍牙連入（classic SPP）、SSH 連入三張卡：開關與狀態燈、裝置識別碼／名稱／MAC，以及**依作業系統分頁的連線指引**（macOS／Windows／iPhone／Android，見 §5） |
| **網頁終端** | 用瀏覽器連進被接設備的 console（最常用，見 §5.1） |
| **檔案伺服器** | 把韌體檔上傳到 AirTTY A1，讓設備自己用 TFTP／HTTP／FTP／SCP 抓檔升級 |
| **網路工具** | 用 CDP／LLDP 看「這台 AirTTY A1 接在哪台交換器的哪個埠」 |
| **封包擷取** | 讓筆電上的 Wireshark 遠端抓 AirTTY A1 這一側的封包 |

> 另外，左側選單 **系統 → Custom Commands** 內建 6 個一鍵診斷按鈕（路徑追蹤、頻寬測試、封包擷取、序列埠狀態、系統狀態、LAN 裝置掃描），現場排查很好用；**狀態 → vnStat 流量監控**可看歷史流量圖。

## 4. 接上你的設備

### 4.1 接線

1. 把 USB 序列轉接線（或 USB console 線）的 **USB 端插到 AirTTY A1 的 USB 埠**。
2. 另一端（DB9 / Cisco RJ45 / micro-USB console…）接到目標設備的 **console 埠**。
3. 插上後**不需要任何設定**，儀表板的「序列裝置」區會在數秒內自動出現一張卡，上面顯示偵測到的晶片型號與裝置名稱。

> 📷 *（截圖待補：序列裝置卡）*

> ⚠️ **請透過 USB hub 連接序列轉接頭**（一般帶 TT 的 USB 2.0 hub 即可；若隨貨有附 hub，直接用附的那顆）。
> AirTTY A1 的處理器對 USB 全速（full-speed）裝置有硬體限制，**部分序列轉接頭直接插機身 USB 埠不會被辨識**；插在 hub 上就正常。若你直插後儀表板沒有出現裝置卡，第一件事就是改插 hub。
> 同一顆 hub 也可以同時掛藍牙介面卡與第二個序列轉接頭。

### 4.2 支援的序列轉接晶片

| 晶片 | 常見名稱 |
| --- | --- |
| **FTDI** | FT232R / FT232RL 等 |
| **CP210x** | CP2102 / CP2104 |
| **CH340 / CH341** | 常見平價轉接線 |
| **PL2303** | Prolific |
| **USB CDC-ACM** | 設備原生 USB console（如 Cisco 的 mini-USB console 埠） |

驅動程式已內建，插上即用。裝置卡上會直接顯示辨識到的晶片名稱與 USB ID，可用來確認是不是插對線。

### 4.3 設定序列參數

在儀表板的「序列裝置」卡上：

1. 依序選擇 **鮑率（Baud）**、**資料位元**、**校驗（Parity）**、**停止位元**、**流量控制**。
   - 可選鮑率：300 / 1200 / 2400 / 4800 / 9600 / 19200 / 38400 / 57600 / 115200 / 230400。
   - 網路設備最常見的是 **9600 8N1**（無流控）；部分設備用 115200。
2. （選用）在「埠位標籤」欄填一個好認的名字，例如 `機房核心SW`。多台設備時很有用。
3. **勾選「🔒 連線密碼保護」並設定密碼**（4～63 字元）。
   出廠已預設啟用連線密碼，**出廠預設值一律為 `AirTTY`**（每台都相同）；建議在這裡改成自己的密碼。
4. 按 **「💾 套用設定」**。畫面會提示已套用的鮑率與 Telnet 埠號。

> ℹ️ **「連線密碼」與「管理密碼」是兩回事**：
> - **管理密碼**：登入 `http://192.168.10.1` 管理介面用。
> - **連線密碼**：任何人要連進 console（不論網頁、Telnet、藍牙、SSH）都要先通過的那道門。
> 這道門一設，**五種連線方式全部生效**，不必分別設定。

### 4.4 接第二個序列埠

透過 USB hub 可以同時接兩個序列轉接頭，儀表板會出現兩張裝置卡，各自獨立設定參數與密碼；對外的 Telnet 埠分別是 **4001** 與 **4002**。

### 4.5 腳位與轉接頭速查

新手最常見的「設備壞掉」其實是 **TX/RX 反接或用錯線**。速查：

**Cisco 式 RJ45 console 埠（藍色 rollover 全反線）**

| RJ45 腳位 | 訊號 | 對接 DB9 |
| --- | --- | --- |
| 3 | TxD（設備送出） | 2（RxD） |
| 6 | RxD（設備接收） | 3（TxD） |
| 4／5 | GND | 5 |

> 全反線的特徵：兩端 RJ45 的線序**完全相反**（1↔8、2↔7…）。拿一般網路線（直通線）接 console 是不通的。

**DB9（RS-232 DTE）常用腳位**：2=RxD、3=TxD、5=GND；跳線把 2-3 交叉的叫 null modem 線。

**USB 轉接頭**：AirTTY 支援的晶片見 §4.2；接上後裝置卡會顯示晶片型號，
「有畫面但打字沒反應」多半是 TX/RX 反接或流控沒關（見 §7 決策樹）。

**四大廠牌 console 常見預設值**（個別機型以原廠文件為準）：

| 廠牌 | 鮑率 | 資料/校驗/停止 | 流控 |
| --- | --- | --- | --- |
| Cisco IOS | 9600 | 8-N-1 | 無 |
| Juniper Junos | 9600 | 8-N-1 | 無 |
| Fortinet FortiGate | 9600 | 8-N-1 | 無 |
| HPE ProCurve／Aruba CX | 9600（舊）／115200（CX） | 8-N-1 | 無 |
| Linux 伺服器 | 115200（常見） | 8-N-1 | 無 |

## 5. 五種連進 console 的方式

五條路最後都通到同一個 console 畫面，也都由**同一組連線密碼**把關。挑一條你順手的即可。

| 方式 | 適合誰 | 要裝軟體嗎 |
| --- | --- | --- |
| §5.1 網頁終端 | 所有人；最快上手 | 不用 |
| §5.2 Telnet / Raw TCP 4001 | 習慣 PuTTY、SecureCRT 的人 | 用你原本的終端軟體 |
| §5.3 Web 藍牙終端 | Windows / macOS / Android，不想連 WiFi 時 | 不用（Chrome 或 Edge） |
| §5.4 iPhone / iPad | 現場只帶手機 | 要裝 BTerm |
| §5.5 Windows 傳統藍牙 SPP | 要用系統 COM 埠工具的人 | 用你原本的終端軟體 |

> 📌 **同時連線數**：每個序列埠預設同時最多 **2 條**連線（網頁 + Telnet 合計）。超過時新連線會收到「連線已滿」的提示；此時可到儀表板的裝置卡上按 **「✕ 中斷此連線」**釋放名額。

---

### 5.1 網頁終端（最簡單）

**適用場景**：任何情況下的第一選擇。只要能連上 AirTTY A1 的 WiFi，開瀏覽器就能用，不必安裝任何軟體。

**步驟**

1. 連上 AirTTY A1 的 WiFi（§3.1）。
2. 瀏覽器開 `http://192.168.10.1` 並登入。
3. 左側選單進入 **AirTTY → 網頁終端**。
4. 選擇要連的序列埠，按 **「連線」**。
5. 畫面出現終端機。按一下 Enter，若設備有輸出就會看到 console 提示字元。

> 📷 *（截圖待補：網頁終端畫面）*

**這個終端能做的事**（一般 console 軟體要另外設定的功能，這裡直接在畫面上）：

- 連線中**即時修改**鮑率、資料位元、校驗、停止位元、流量控制。
- 送出 **BREAK** 訊號（進 ROMMON／中斷開機用）。
- 控制 **DTR / RTS**，並即時顯示 DCD / CTS / DSR / RI 狀態燈。
- **快捷鍵列**（v1.2 起）：Tab、Esc、?、Enter、Ctrl+C/Z/^/A/D/U/W、方向鍵一按即送，
  手機平板沒有實體 Ctrl／方向鍵也能操作；「Ctrl…」鈕按一下後，下一個敲的鍵自動轉成 Ctrl 組合。
- **📋 貼上**：從剪貼簿貼上並送出，多行內容會先顯示行數與第一行讓你確認（誤貼整頁設定是會出事的）。
- **💾 下載 Log**（v1.2 起）：把本頁累積的終端輸出下載成純文字檔（已濾除終端控制碼），
  斷線後也能下載 —— 排障記錄、驗收留檔直接存。
- **📄 維運報告**（v1.6 起）：一鍵把側錄輸出＋連線資訊＋AI 問答摘要（若有）組成
  列印友善頁面，直接存成 PDF 交給客戶或主管。
- **廠牌智慧快捷鈕**（v1.6 起）：偵測到 Cisco／Junos／Fortinet／Aruba／Linux 的輸出時，
  自動出現該廠牌常用巡檢指令按鈕；收到疑似亂碼時會提示一鍵切換鮑率。
- **🤖 AI 排障助手**（v1.6 起）：用你自己的 AI 金鑰（Gemini 或 OpenAI 相容端點，
  只存在你的瀏覽器）詢問「這段錯誤是什麼」。附上的輸出會**自動遮蔽**
  （遮蔽 IP 尾兩節、MAC 裝置碼、密碼欄位），且**送出前一定先顯示可編輯的預覽**讓你確認 ——
  內容由你的瀏覽器直送 AI 服務，裝置與 AirTTY 官方都不經手。

**疑難**

| 現象 | 處理 |
| --- | --- |
| 終端顯示「連線已滿」 | 已達同時連線上限；到儀表板中斷一條既有連線 |
| 終端顯示「認證失敗或來源已被鎖定」 | 連線密碼錯，或同一來源錯太多次被暫時鎖定（見 §7） |
| 畫面全黑、按 Enter 沒反應 | 序列參數（鮑率）不對，或線沒接到設備的 console 埠；見 §7 |
| 改了設定後畫面沒反應 | 變更序列參數後，正在連的那一條需要**斷線重連**才會套用 |

### 5.2 Telnet / Raw TCP 4001（PuTTY、SecureCRT、nc）

**適用場景**：你已經習慣 PuTTY／SecureCRT／Tera Term 的操作與 log 功能，想沿用原本的工具與工作流程。

**連線資訊**

| 項目 | 值 |
| --- | --- |
| 主機 | `192.168.10.1` |
| 連接埠 | **4001**（第一個序列埠）／ **4002**（第二個） |
| 連線類型 | **Telnet** |

**步驟（PuTTY）**

1. 連上 AirTTY A1 的 WiFi 或接網路線。
2. 開 PuTTY → Connection type 選 **Telnet**。
3. Host Name 填 `192.168.10.1`、Port 填 `4001` → **Open**。
4. 畫面出現 `Password:` → 輸入**連線密碼**（不會顯示星號，直接打完按 Enter）。
5. 通過後即進入設備 console。

**步驟（macOS / Linux 命令列）**

```
telnet 192.168.10.1 4001
```

或

```
nc 192.168.10.1 4001
```

**進階：虛擬 COM 埠 / RFC2217**

若你的終端軟體支援 **RFC2217（telnet com-port）**，連 `192.168.10.1:4001` 並選擇 RFC2217 協定，就能從自己的軟體端直接控制鮑率、BREAK、DTR/RTS 與讀取 modem 狀態。

**疑難**

| 現象 | 處理 |
| --- | --- |
| 密碼輸入三次都失敗就被斷線 | 正常保護行為，重連即可；同一來源錯 5 次會被鎖 300 秒 |
| 出現「連線已滿」後斷線 | 已達同時連線上限，見 §5 開頭 |
| 連上後停在 `Password:` 沒動作，約 30 秒後被斷線 | 這是防止佔位的保護；重連並儘快輸入密碼 |

### 5.3 Web 藍牙終端（Windows / macOS / Android 建議路徑）

**適用場景**：不想切換 WiFi（例如筆電正連著公司網路要查資料）、或現場 WiFi 訊號很吵時。**不必安裝任何軟體、不必配對**，用 Chrome 或 Edge 開一個網頁就能連。

> 🌐 頁面網址：**<https://airtty.github.io/webterm/>**
> 「連入方式」頁的「藍牙序列（BLE）」卡片上也會直接出現這個連結。
> 機房沒有網路時也能用 —— 事先把該頁下載到筆電、本機起一個 HTTP 伺服器即可，作法見
> [網頁藍牙終端說明](https://github.com/AirTTY/airtty.github.io/blob/main/webterm/README.md)。

**步驟**

1. 在 **「連入方式」** 頁的「藍牙序列（BLE）」卡片確認開關已啟用，狀態顯示 **「廣播中（可被掃到）」**。
2. 用 **Chrome 或 Edge** 開啟上面的網頁終端網址。
3. 按 **「選擇裝置並連線」**。瀏覽器會跳出裝置選擇視窗（這是瀏覽器的安全規定：一定要由你親自點選裝置，網頁不能自己連）。
4. 在清單中選擇你的裝置。
   ⚠️ **從沒連過的裝置，清單上會顯示為「無名稱裝置」**，這是藍牙廣播封包的容量限制，屬正常現象。連過一次之後，清單就會顯示 `AirTTY-A1-xxxx`。多台並存時，可用「連入方式」頁 BLE 卡片上顯示的**識別碼（tag）**與訊號強度來分辨。
5. 連上後按 Enter → 出現 `Password:` → 輸入**連線密碼** → 進入 console。

**疑難**

| 現象 | 處理 |
| --- | --- |
| 瀏覽器沒有跳出裝置選擇視窗 | 請確認用的是 Chrome 或 Edge。**Safari 不支援**網頁藍牙（iPhone / iPad 請改用 §5.4） |
| 清單裡掃不到任何裝置（Android） | Android 掃描 BLE **強制需要位置權限**：Android 12 以上要允許「附近的裝置」，Android 11 以下要允許「位置」**並開啟系統定位服務**。只開藍牙會完全掃不到 |
| 掃得到但連不上 | BLE **一次只能一台裝置連線**。請確認沒有其他人／其他裝置正連著（「連入方式」頁的 BLE 卡片會顯示「使用中」） |
| Windows 第一次連線失敗 | 頁面已內建自動重試；若仍失敗，關掉頁面重開再試一次 |
| 連線中途斷掉 | 頁面會出現「重新連線」按鈕，按一下即可接回同一台裝置 |

### 5.4 iPhone / iPad：BTerm App（藍牙 BLE）

**適用場景**：現場只帶手機，或不方便讓筆電離開原本的網路。iOS 的 Safari 不支援網頁藍牙，因此 iPhone 走 App。

**步驟**

1. 在 **「連入方式」** 頁的「藍牙序列（BLE）」卡片確認開關已啟用、狀態為「廣播中」。
2. 從 App Store 安裝下列其中一款 App。**這兩款用關鍵字搜尋都不容易找到，請直接點連結：**
   - ⭐ **首選：BTerm**（開發者 Hangzhou Liangjiang Network Technology）—— 針對網管 console 情境設計，內建 ESC／TAB／CTRL／方向鍵／Enter 鍵，可存 log。
     👉 <https://apps.apple.com/tw/app/bterm/id1645558277>
   - **第二推薦：Bluefruit Connect**（開發者 Adafruit）—— 實測可完整互動；請選 **UART 模式**，並把換行（EOL）設成 **CR**。
     👉 <https://apps.apple.com/tw/app/bluefruit-connect/id830125974>
3. 開啟 App → 掃描 → 連線本機。
   ⚠️ **清單可能顯示為未命名裝置**（藍牙廣播放不下名稱），連上後才會出現 `AirTTY-A1-xxxx`。多台並存時靠近一點、依訊號強度判斷。
4. 按 Enter → 出現 `Password:` → 輸入**連線密碼** → 再按一次 Enter 即見 console。

**疑難**

| 現象 | 處理 |
| --- | --- |
| 停在 `Password:` 超過 30 秒被斷線 | 未通過密碼的連線 30 秒無輸入會自動斷開（防佔位）；重連並儘快輸入密碼 |
| 掃不到 | 確認沒有其他人正連著（BLE 一次只能一條連線）；「連入方式」頁的卡片是否顯示「廣播中」 |
| 不想用藍牙 | 改用手機連 AirTTY A1 的 WiFi，Safari 開 `http://192.168.10.1` 走網頁終端（§5.1） |

> 其他 iOS App 實測：nRF Toolbox 只能監看、送不出換行；不建議使用 BLESerial nRF。

### 5.5 Windows 傳統藍牙 SPP + PuTTY

**適用場景**：不使用 Chrome／Edge，或你的工具（SecureCRT、Tera Term、自製腳本）必須吃**系統 COM 埠**。

**步驟**

1. 在 **「連入方式」** 頁的 **「藍牙連入（classic SPP）」** 卡片按 **「📡 開啟配對窗（120 秒）」**。
2. Windows → **設定 → 藍牙與裝置 → 新增裝置**，選擇 `AirTTY-A1-xxxx` 完成配對。
   ⚠️ 若清單出現兩個相近的項目，請配對**「序列 / EDR」**那一個，不要配 LE 項目。
3. **找出正確的 COM 埠**（最容易卡住的一步，見下）。
4. 開 PuTTY → Connection type 選 **Serial** → Serial line 填該 COM 埠 → **Open**。
   速度（baud）填多少都可以，SPP 是虛擬埠不受影響；真正的序列參數以儀表板上的設定為準。
5. 出現 `Password:` → 輸入**連線密碼** → 進入 console。

#### ⚠️ 配對後會生出「兩個」COM 埠，只有一個能用

| 事實 | 說明 |
| --- | --- |
| 配對**一台**藍牙裝置，Windows 會生**兩個** COM 埠 | 一個是「**傳入（Incoming）**」、一個是「**傳出（Outgoing）**」 |
| 在裝置管理員裡外觀完全一樣 | 全都叫「透過藍牙連結的標準序列 (COMx)」，加上系統原有的，一整排長得一模一樣 |
| **逐一試會有一半註定失敗** | 傳入埠是「等對方主動連進來」用的，PuTTY 接上去只會空等 —— 這最容易被誤判成「裝置壞了」 |

**你要的是「傳出（Outgoing）」那一個。** 兩種找法：

**方法 A — PowerShell 一行直接命中**（把 MAC 換成你的裝置位址，去掉冒號）：

```powershell
Get-PnpDevice -Class Ports | Where-Object InstanceId -match 'AABBCCDDEEFF'
```

裝置的藍牙 MAC 位址在「連入方式」頁的「藍牙連入（classic SPP）」卡片上直接顯示；卡片也已經幫你把上面這行指令**填好 MAC 並附複製按鈕**，複製貼上即可。

**方法 B — 圖形介面**：
**設定 → 藍牙與裝置 → 更多藍牙設定 → 「COM 連接埠」分頁**，會直接列出「連接埠 / 方向 / 名稱」對照表 —— 認明**方向 = 傳出**那一列。

> 📷 *（截圖待補：Windows COM 連接埠分頁）*

> 💡 COM 埠編號**配對一次後就固定不變**，查一次記起來即可（除非你把裝置從 Windows 移除重新配對）。

**疑難**

| 現象 | 處理 |
| --- | --- |
| PuTTY 開了 COM 但畫面空白、打字沒反應 | 十之八九選到「傳入」埠，改用「傳出」那一個 |
| 找不到裝置可配對 | 配對視窗只開 **120 秒**，過期請回「連入方式」頁重按一次；平時裝置刻意不可被搜尋，這是安全預設 |
| 想解除配對 | 「連入方式」頁的 SPP 卡片上有「✕ 解除配對」；Windows 端也要一併移除 |

### 5.6 補充：SSH 直連序列埠

若你的工作流程偏好 SSH，可在 **「連入方式」** 頁的 **「SSH 連入」** 卡片啟用此功能並設定 SSH 登入密碼（8～64 字元），之後即可：

```
ssh port1@192.168.10.1
```

## 6. 上游 WiFi 與軟體更新

平常 AirTTY A1 是**獨立運作**的：自己發 WiFi，你連上去用，不需要外部網路。

### 6.1 什麼時候需要上游 WiFi

只有這兩種情況：

1. **要自動校正時間** —— 裝置沒有內建時鐘電池，開機時間會不準；連上有網路的熱點後會自動對時。
2. **要安裝額外套件／存取外部資源**。

其餘時候**建議保持關閉**。

### 6.2 設定並連上熱點

1. 用手機開一個個人熱點，或準備一台 2.4GHz 的分享器。
   ⚠️ **AirTTY A1 只支援 2.4GHz**。iPhone 熱點請開啟「**最大化相容性**」，並停留在個人熱點畫面直到連上。
2. 在儀表板的 **「上游 WiFi（WAN）」** 卡片填入目標網路：
   - **目標網路**欄 → 熱點的 WiFi 名稱（SSID）。
   - **密碼**欄 → 該熱點的密碼。
   - 按 **「💾 儲存並套用」**。
3. 勾選卡片上的 **「連上游 WiFi」**。
4. 卡片會依序顯示「搜尋上游中…」→「已連上 〈網路名稱〉（訊號 dBm），IP xxx.xxx.xxx.xxx」。

> 📷 *（截圖待補：上游 WiFi 卡片）*

> ℹ️ **出貨時未預設任何上游 WiFi**（每個使用環境不同），第一次使用時卡片會顯示「尚未設定上游 WiFi」，這是正常的 —— 照上面步驟 2 填一次即可。
> - 只支援**有密碼的 WPA2／WPA3 網路**（密碼 8～63 字元），**不支援無密碼的開放網路**。
> - 密碼基於安全考量**永遠不會顯示出來**。之後若只想換網路名稱，密碼欄**留空**即代表沿用原本的密碼。
> - ⚠️ 按下「儲存並套用」後裝置會重新載入無線設定，**本機 WiFi 會短暫斷線數秒**屬正常現象，稍候重新整理頁面即可。

### 6.3 用完請關掉 —— 以及裝置會自動幫你關

AirTTY A1 只有一張無線網卡，同時要發自己的 WiFi、又要去連別人的 WiFi，因此：

- **連上上游後，本機 WiFi 會跳到上游的頻道**，這是正常現象。
- **上游熱點關掉、或找不到目標網路時，裝置會拚命搜尋，反而讓自己的 WiFi 變得很難連**。

為此內建了自動保護：**上游 WiFi 開著但持續連不上時，約 120 秒後裝置會自動退回獨立模式**（關閉上游 WiFi），讓你的手機／筆電能正常連回來。下次要用時再勾選一次即可，卡片上會註明「上次因持續找不到上游，已由裝置自動停用」。

> 💡 **用完就關**，是最省事的習慣。

### 6.4 沒有網路時的校時

沒有外部網路時，裝置時鐘會慢慢偏移（log 時間戳會不準）。此時儀表板頁首會出現提示與一顆按鈕：

**「以瀏覽器時間校時」** —— 按一下，裝置就會把時間校正成你電腦／手機當下的時間。提示列會自動消失。

---

### 6.5 軟體更新（v1.4.0 起）

AirTTY 的功能更新以「單一升級檔」發布（檔名如 `airtty-update-v1.4.0.run`）。有兩種更新方式：

**方式一：線上更新（v1.5.0 起，最簡單）**

1. 進 **AirTTY → 儀表板 → 軟體更新**，按 **「🔍 檢查更新」** —— 只要**你的電腦**能上網就查得到
   （會顯示新版號與官方更新說明）。
2. 若裝置已連上游 WiFi（§6.2），按 **「⬆️ 線上更新」**，裝置會自行下載、驗證並完成更新。
3. 裝置沒有連外網也沒關係：按 **「💾 下載到電腦」** 存檔，再用方式二上傳。

**方式二：手動上傳**

1. 到官方發行頁 **<https://github.com/AirTTY/airtty.github.io/releases/latest>** 下載最新的
   `airtty-update-vX.Y.Z.run`，存到你的電腦（頁面同時有該版的更新說明）。
2. 登入管理介面，進 **AirTTY → 儀表板**，找到「**軟體更新**」區塊。
3. 按 **「📦 上傳升級檔並更新」**，選擇 `.run` 檔，確認後裝置會自動完成更新
   （約 10～30 秒，期間終端連線會短暫斷開）。
4. 完成後頁面自動重新整理，儀表板頂部的版本號會變成新版。

> ✅ 更新**不會**動到你的設定：序列埠綁定、連線密碼、WiFi 設定全部保留。
> 升級檔內建完整性驗證（sha256），傳輸損壞會拒絕安裝並提示重傳。

### 6.6 ⚠️ 請勿自行更新 OpenWrt 韌體

AirTTY 的系統以 OpenWrt 為基礎客製，**底層韌體與記憶卡是一體設計**。
自行刷入官方或第三方 OpenWrt 韌體會使記憶卡上的整套 AirTTY 功能無法啟動，
輕則產品功能全失、重則裝置無法開機 —— 這類損壞**不在保固範圍**。

- 因此管理介面**刻意不提供**「更新韌體」頁面。
- 一般功能更新一律走上一節的**軟體更新**，不需要動韌體。
- 若未來有必須更新底層韌體的版本，會隨升級檔附上官方工具與步驟說明。

## 7. 疑難排解 FAQ

### 三步決策樹（先走這裡再看個別條目）

```
症狀 A:連得上 AirTTY 的 WiFi,但網頁打不開
  → 電腦/手機拿到的 IP 是不是 192.168.10.x?
  → 網址用 http://192.168.10.1(不是 https)
  → 還是不行:看「連不上裝置的 WiFi」條目

症狀 B:終端有畫面,但敲鍵盤沒反應
  → 線是不是 console 線(rollover)?TX/RX 有沒有反接?(§4.5)
  → 流控(Flow control)改成「無流控」再試
  → 按一下 Enter;某些設備要喚醒才吐提示字元

症狀 C:終端出現亂碼(���、方塊字)
  → 九成是鮑率不符 —— v1.6 起畫面會自動提示一鍵切換
  → 對照 §4.5 廠牌預設值表:Cisco/Juniper/Fortinet 先試 9600,Linux 先試 115200
```


### 連不上裝置的 WiFi

| 檢查 | 說明 |
| --- | --- |
| 開機完成了嗎 | 藍燈不是電源燈。等約 1 分鐘讓 SSID 出現 |
| **上游 WiFi 是不是開著、而熱點沒開？** | 這是最常見的原因。裝置會為了找上游而不停掃描，導致自己的 WiFi 幾乎掃不到。**關掉上游 WiFi 開關**即可（或等約 120 秒讓裝置自動退回獨立模式）。臨時要進管理介面可改用**網路線**接 RJ45 孔 |
| 你的裝置只支援 5GHz 嗎 | AirTTY A1 只有 2.4GHz |
| 密碼對嗎 | 出廠預設 WiFi 密碼是 `AirTTY-A1`（見 §8.4）；改過的話請用你自己設定的那組 |

### 開啟上游 WiFi 後,AirTTY 自己的 WiFi 會消失嗎?

**不會。** AirTTY 的熱點（AP）與上游 WiFi（STA）是**同時並存**的,你連著 AirTTY 操作的同時
它可以另外連出去。而且有看門狗保護:上游一直連不上時會自動停用 STA,
**絕不會讓自家熱點消失**。唯一的暫態是套用上游設定的瞬間 WiFi 會重載、斷線數秒,屬正常。

### 序列埠沒有輸出、畫面全黑

依序檢查：

1. **鮑率對不對** —— 最常見。網路設備多為 9600 或 115200，在儀表板改看看（改完正在連的那條要重連）。
2. **線接對了嗎** —— 有些設備的 console 需要特定的接頭／跳線（rollover cable）。
3. **設備真的有在輸出嗎** —— 按 Enter 看看，很多設備要收到輸入才會回應提示字元。
4. **儀表板有沒有出現裝置卡** —— 沒出現代表轉接頭沒被辨識，請改插 USB hub（§4.1）。
5. 出現亂碼 = 鮑率或校驗設定不符，不是壞掉。

### 儀表板看不到序列轉接頭

1. 改插 **USB hub**（見 §4.1 的說明，這是機器的硬體特性）。
2. 換一條 USB 線試試（部分線材只有充電功能、沒有資料線）。
3. 若原本看得到、突然消失 → 見下一則。

### 藍牙或序列埠「突然消失」

AirTTY A1 的 USB 供電預算有限（設計為 5V/1A）。當藍牙介面卡、序列轉接頭、記憶卡同時工作，又剛好在充電時，可能出現**開機後藍牙或序列埠沒有出現**、或使用中突然一起消失的情況。

**處理方式**：

1. **重新開機**（長按電源鍵關機，再長按開機）—— 絕大多數情況一次就恢復。
2. 接上充電線再使用，供電較穩定。
3. 若只是要用序列 console、暫時不需要藍牙，可以把藍牙介面卡拔掉，負載會明顯下降。

### 藍牙掃不到裝置

| 檢查 | 說明 |
| --- | --- |
| 是不是已經有人連著 | **BLE 一次只允許一條連線**。「連入方式」頁的 BLE 卡片顯示「使用中」時，別人就掃不到／連不上 |
| 「連入方式」頁卡片狀態 | 需顯示「廣播中（可被掃到）」；顯示「dongle 不在」代表藍牙介面卡沒插好 |
| Android 權限 | 必須允許「附近的裝置」（Android 11 以下需「位置」權限**且開啟定位服務**）—— 只開藍牙一定掃不到 |
| 清單是「未命名裝置」 | 這是正常的（廣播封包放不下名稱），連過一次後就會顯示名稱 |
| 剛剛才斷線 | 系統層釋放需要幾十秒，稍等再掃 |

### 密碼輸入正確卻連不上

- 同一來源**連續錯 5 次會被鎖 300 秒**，等 5 分鐘再試。
- 連線密碼與管理密碼是兩組不同的密碼（見 §4.3 的說明）。
- 網頁終端顯示「認證失敗或來源已被鎖定」即屬此類。

### 顯示「連線已滿」

每個序列埠預設同時最多 2 條連線。到儀表板的裝置卡下方「即時連線」區，按 **「✕ 中斷此連線」**踢掉不需要的那條（只斷那一條，不影響其他人，也不會停用服務）。

### 裝置時間不對 / log 時間戳很奇怪

裝置**沒有內建時鐘電池**，每次開機時間都會重置。

- 有外部網路時：連上上游 WiFi 會自動校時（§6.2）。
- 沒有外部網路時：按儀表板頁首的 **「以瀏覽器時間校時」**（§6.4）。

### 電量燈的意思

短按電源鍵，5 顆綠燈會亮 6～7 秒顯示電量，**每顆約 20%**（4 顆亮 ≈ 80%）。充電中時，代表當前級距的那一顆會閃爍。

管理介面只顯示「充電中／未在充電」，**不顯示百分比** —— 這台機器的硬體不提供可讀的電量數值，要看電量請按電源鍵。

### 記憶卡指示燈（紅／橘燈）一直亮著

有插卡時它本來就恆亮，讀寫時閃爍，這是正常的。**不要在開機狀態下拔卡**（見 §8）。

## 8. 規格與安全注意

### 8.1 電池安全

- 內含**鋰離子電池**（5200mAh / 19.24Wh）。請勿穿刺、拆解、重壓、投入火中或浸水。
- 充電請使用 **5V / 1A** 規格的 USB 充電器與品質良好的 micro-USB 線。裝置的充電輸入上限就是 1A，**換更大的充電器不會讓它充得更快**。
- **操作溫度 0°C ～ 40°C**。請勿放在密閉的高溫環境（例如夏天車內）長時間充電或使用。
- 若發現機身異常鼓脹、發燙、變形或有異味，**立即停止使用並斷開電源**，勿再充電。
- 長期存放建議保持約半電量，並每隔數月補充電一次。

### 8.2 使用注意

- ⚠️ **請勿在開機狀態下拔除記憶卡**。卡片是系統的一部分（存放系統擴充空間），拔除會導致功能異常。要更換請先關機。
- ⚠️ 本裝置的 USB 埠設計上是給序列轉接頭／藍牙介面卡／USB hub 使用，**請勿用來替手機等大電流裝置充電**，會造成本機供電不穩。
- 本裝置的 WiFi 為 **2.4GHz** 頻段。機房內金屬機櫃會明顯衰減無線訊號（WiFi 與藍牙皆然），連線不穩時請縮短距離、或把裝置移到機櫃外側。
- 管理介面走 HTTP（未加密），**請勿把本裝置接上不受信任的網路**，並務必更改出廠預設密碼。

本批機器為**庫存新品改裝**：原廠庫存機拆封後安裝本產品韌體，**未經使用，外觀近全新**。
