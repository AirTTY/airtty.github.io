# AirTTY A1 硬體規格

**現役出貨機種** —— 內建 5200mAh 電池的可攜式無線 console 伺服器。

基礎硬體為 Gigastone A4-52ER，刷入以 OpenWrt 為基礎的自製韌體。

> 操作方式與疑難排解請見 [A1 使用手冊](../../docs/manual-a1.md)。

## 支援的 USB 序列轉接晶片

驅動程式已內建於韌體，插上即用。裝置卡上會直接顯示辨識到的晶片名稱與 USB ID，
可用來確認是不是插對線。

| 晶片 | 常見名稱 |
| --- | --- |
| **FTDI** | FT232R / FT232RL 等 |
| **CP210x** | CP2102 / CP2104 |
| **CH340 / CH341** | 常見平價轉接線 |
| **PL2303** | Prolific |
| **USB CDC-ACM** | 設備原生 USB console（如 Cisco 的 mini-USB console 埠） |

支援的序列參數：

- 鮑率 300 / 1200 / 2400 / 4800 / 9600 / 19200 / 38400 / 57600 / 115200 / 230400
- 資料位元、校驗、停止位元、流量控制皆可設定，並可在連線中即時修改
- 最多同時接**兩個**序列埠（透過 USB hub）

## 注意事項

### ⚠️ 請透過 USB hub 連接序列轉接頭

一般帶 TT 的 USB 2.0 hub 即可（若隨貨有附 hub，直接用附的那顆）。

AR9331 對 USB 全速（full-speed）裝置有硬體限制，**部分序列轉接頭直接插機身 USB 埠不會被辨識**；
插在 hub 上就正常。若直插後儀表板沒有出現裝置卡，第一件事就是改插 hub。
同一顆 hub 也可以同時掛藍牙介面卡與第二個序列轉接頭。

### ⚠️ 請勿在開機狀態下拔除記憶卡

卡片是系統的一部分（存放系統擴充空間），拔除會導致功能異常。要更換請先關機。

### ⚠️ USB 供電預算有限

本裝置的 USB 埠設計為 5V/1A，是給序列轉接頭／藍牙介面卡／USB hub 使用，
**請勿用來替手機等大電流裝置充電**。

當藍牙介面卡、序列轉接頭、記憶卡同時工作又剛好在充電時，偶爾會出現開機後藍牙或序列埠
沒有出現、或使用中一起消失的情況 —— 重新開機幾乎都能恢復。
建議**同時使用藍牙與序列轉接頭時全程接著充電線**，供電較穩定。

### 電池安全

- 內含**鋰離子電池**（5200mAh / 19.24Wh）。請勿穿刺、拆解、重壓、投入火中或浸水。
- 充電請使用 **5V / 1A** 規格的 USB 充電器與品質良好的 micro-USB 線。
  裝置的充電輸入上限就是 1A，**換更大的充電器不會讓它充得更快**。
- **操作溫度 0°C ～ 40°C**。請勿放在密閉的高溫環境（例如夏天車內）長時間充電或使用。
- 若發現機身異常鼓脹、發燙、變形或有異味，**立即停止使用並斷開電源**，勿再充電。
- 長期存放建議保持約半電量，並每隔數月補充電一次。

### 無線環境

WiFi 為 **2.4GHz** 頻段（不支援 5GHz）。機房內金屬機櫃會明顯衰減無線訊號（WiFi 與藍牙皆然），
連線不穩時請縮短距離、或把裝置移到機櫃外側。

### 網路安全

管理介面走 HTTP（未加密），**請勿把本裝置接上不受信任的網路**，並務必更改出廠預設密碼。

序列埠**連線密碼**的出廠預設一律固定為 **`AirTTY`**（每台都相同，公開於使用手冊），
請在儀表板的「序列裝置」卡片改成自己的密碼。
