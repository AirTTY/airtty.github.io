# AirTTY M2 硬體規格

> ## 🚧 規劃中，尚未出貨
>
> 本頁記錄的是 M2 的**規劃方向與已知硬體規格**。M2 目前沒有出貨時程，本頁內容可能變動。
> 標示「待確認」的項目表示尚未實測驗證，**請勿據以採購或規劃導入**。
> 現在買得到的是 [AirTTY A1](../a1/README.md)。

M2 的基礎硬體為 GL.iNet GL-MT300N-v2（Mango），改由**外接行動電源**供電。
已實測本體可正常運行。

---

## 與 A1 的差異

差別集中在**供電形態**，其餘操作方式與軟體功能規劃為一致。

| | **A1**（現役） | **M2**（規劃中） |
| --- | --- | --- |
| 電源 | **內建鋰電池 5200mAh**，開箱即用 | **外接行動電源**（micro-USB 5V/1A 輸入） |
| 續航 | 固定，受電池健康度影響 | **取決於你接的行動電源** —— 容量自選，要撐久就換大顆 |
| 電池更換 | 內建，不易更換 | **電池即一般行動電源，壞了自己換**，電池壽命不綁主機 |
| 隨身負擔 | 一件 | 兩件（主機 + 行動電源） |
| 二手電池風險 | 有（見 A1 頁的二手品狀態說明） | **無**（主機不含電池） |
| 有線網路孔 | 1 × RJ45 | 2 × RJ45（1 LAN + 1 WAN） |
| 命名由來 | **A** = All-in-one（內建電池） | **M** = Modular（電源模組化） |

> 型號的**字首代表形態、數字代表世代**：電池的有無是形態差異，不是新舊之分。
> M2 並非「A1 的升級版」，兩者是給不同使用習慣的人選的。

## 已知規格

以下為 GL-MT300N-v2 的硬體規格（依機身標籤與實機確認）：

| 項目 | 規格 |
| --- | --- |
| 處理器 | MediaTek MT7628AN（MIPS 24Kc） |
| 記憶體 / 內部儲存 | 128MB DDR2 RAM / 16MB Flash |
| 無線網路 | WiFi 802.11 b/g/n 300Mbps，**僅 2.4GHz**，內建天線 |
| 有線網路 | 1 × LAN + 1 × WAN，10/100 Mbps |
| USB | 1 × USB 2.0 Host |
| 電源輸入 | micro-USB **5V ⎓ 1A**（機身標籤實測值） |
| 本體功耗 | 約 2.75W 以下 |
| 操作溫度 | 0°C ～ 40°C（存放 -20°C ～ 70°C） |
| 其他實體介面 | Reset 鍵、Mode 撥動開關、3 顆 LED（電源／WAN／WLAN） |

## 待確認項目

以下項目**尚未驗證**，不列入規格：

| 項目 | 狀態 |
| --- | --- |
| 韌體功能是否與 A1 完全對等 | **待確認** —— 兩者為不同 SoC 家族（ramips vs ath79），韌體需個別建置與驗證 |
| 藍牙（BLE / 傳統 SPP）支援 | **待確認** —— 同樣走 USB 藍牙介面卡，但供電預算需實測 |
| 可否同時接藍牙介面卡與序列轉接頭 | **待確認** —— 機身只有**一個** USB 埠，需搭配 USB hub，且 5V/1A 的供電預算與 A1 同級吃緊 |
| 支援的序列轉接晶片清單 | **待確認**（預期與 A1 相同，但需實測） |
| 記憶卡擴充 | **無 SD 卡槽** —— 儲存擴充方案待確認 |
| 尺寸、重量 | **待確認** |
| 搭配行動電源的續航 | **待確認** —— 本質上取決於使用者自備的行動電源容量 |
| 隨附配件、出貨形式 | **待確認** |
| 上市時程、價格 | **未定** |
